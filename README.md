# AI 小工具

本地运行的 ChatGPT 账号批量注册与管理工具。**只在你自己的电脑上跑**，不依赖任何服务器。

## 下载

到 [Releases](../../releases/latest) 下载 `ai-tool-v1.0.zip`，
**整个解压**出来后双击 `启动.bat`。

> 文件名请认准 `ai-tool-v1.0.zip`。这是永久链接，换版本也不会失效。

## 它能做什么

- 批量注册 ChatGPT 账号：自动取邮箱验证码、填资料、拿凭证
- 可选：注册后自动设置登录密码并绑定 TOTP 认证器 2FA
  （**建议开** —— 短信/邮件验证码注册出来的号本来没有密码，二次登录只能再取一次邮箱）
- 可选：过手机号验证（要用 Codex 才需要；只生图不需要）
- 账号池：测活、查生图额度、测试生图、导入外部账号
- 导出交付凭证：`邮箱----密码----2FA密钥`，一行一个，缺的字段写「无」

## 快速开始

1. 把整个压缩包解压出来（**不要**只把单个文件拖出来）
2. 双击 `启动.bat` —— 会弹出一个黑色窗口，**不要关它**；
   一两秒后浏览器会自动打开操作界面
3. 填「工具密钥」，点右边的「保存密钥」
4. 点「开始检查」—— 四项都绿了再点「开始注册」

第一次真正开始注册前需要下载浏览器内核（约 150MB），只下一次。

详细步骤见 `使用说明.txt`。

## 数据与隐私

- 程序只在 `127.0.0.1` 上提供界面；除了你自己配置的代理之外，不连任何第三方服务器
- 账号、配置、日志都在程序文件夹里：

      data/accounts.jsonl   账号记录（含密码和 2FA 密钥）
      data/config.json      你的配置
      logs/                 运行日志

- 备份 = 复制整个文件夹；换电脑也是整个文件夹拷过去
