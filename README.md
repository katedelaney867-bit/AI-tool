# AI 小工具

浏览器自动注册 ChatGPT 账号 + 账号池管理 + 网页版生图的本地小工具。
**双击 `run.bat` 就能用**，不需要懂命令行。

三个页面，各自只做一件事：

| 页面 | 干什么 |
| --- | --- |
| **注册账号** | 用真实浏览器走 ChatGPT 官方注册页，自动收邮箱验证码 |
| **账号池** | 自己注册的、别处导入的账号都放这儿；查额度、导出 |
| **测试生图** | 挑一个账号，写一句话，直接出图 |

- 用真实浏览器（CloakBrowser）操作页面，不是协议发包
- 邮箱和手机号都由**本站号池**统一提供，你只需要一个**工具密钥**
- 生图走 ChatGPT 官网同一条链路，**不需要 Codex OAuth、不需要额外配置**
- 代理自动跟随系统设置，装了 Clash / FlClash 就不用再填一遍
- 所有数据都在本机 `data/` 目录，除了向本站取号和取码，不上传任何地方

## 一、开始使用

### 1. 装 Python

没有 Python 的话先去 <https://www.python.org/downloads/> 装 **3.10 或更高版本**。

> 安装界面底部有个 **Add Python to PATH**，一定要勾上。

### 2. 双击 `run.bat`

第一次运行会自动创建运行环境并安装依赖，需要几分钟（会下载一个约 150MB 的浏览器内核）。
之后再启动就是几秒钟的事。

启动完成后浏览器会自动打开界面：<http://127.0.0.1:8770>

### 3. 只填两个东西，点开始

| 要填的 | 说明 |
| --- | --- |
| **工具密钥** | 登录本站 → 「自建号池」页面 → 生成并复制（`sk-` 开头） |
| **注册数量** | 要注册几个 |

然后点 **开始注册**。剩下的都是自动的：下单邮箱、等验证码、填表、设密码、
按需做桌面端激活（含手机号验证），全程在日志区一步步可见。

> 配置模板在包里的 `config.example.json`：复制到 `data\config.json` 后只填
> `sitepool_tool_key` 一格即可。详见同目录的 `分发配置说明.md`。

## 二、三个页面怎么用

### 注册账号

浏览器会自己开、自己填、自己收验证码。日志区会实时打印每一步，
出问题把日志内容发出来就能定位。

- **并发数**：保持 1。调高会同时开好几个浏览器，更容易被风控。
- 注册成功的账号自动进账号池，不用手动保存。
- 中途可以点「停止」，当前这一单会体面收尾，不会把已经买好的码弄丢。

### 账号池

**导入账号**——从别处拿到的号，粘进文本框就行，支持：

- 整段 ChatGPT session JSON（含 `accessToken` 字段）
- 一整个 token 数组 `[{"accessToken": "..."}, ...]`
- 光秃秃的一条 `access_token`
- 本工具导出的 `accounts_export.json`

解析只在本地做，不联网；导入后会自动读出邮箱、套餐、有效期。
邮箱相同的账号会合并而不是重复添加，注册时记下的密码、订单凭证不会被冲掉。

**查生图额度**——只读，不消耗额度。会告诉你每个号还能生几张图。
额度是 24 小时滚动窗口，重置时间会在日志里打出来。

**导出**——下载 `accounts_export.json`，标准 JSON，可以给别的工具用。

### 测试生图

选账号 → 写提示词 → 开始生成。图片存到 `data/images/`，页面上直接看。

- **模型不需要选**：固定由服务端自动路由，也就是说你拿到的总是当前可用的最新生图模型。
- **比例**：网页版没有 `size` 参数，只能靠提示词影响。下拉里选的比例会
  以「（画面比例 16:9）」追加到提示词末尾，实测有效（能拿到 1672×941 这种横图）。
- **分辨率**：由服务端决定，客户端控制不了。免费账号一般是 1024~1254 边长。

## 三、产出在哪

| 文件 | 内容 |
| --- | --- |
| `data/accounts.jsonl` | 每行一个账号的完整记录（邮箱、token、套餐、额度、查活结果等） |
| `data/accounts_export.json` | 界面上点「导出」生成的汇总文件 |
| `data/images/*.png` | 生成的图片，同名 `.json` 是提示词和服务端模型记录 |
| `data/config.json` | 你填的配置（含工具密钥，注意别外传） |
| `data/codex_credentials/*.json` | 开启桌面端激活后，每个账号的 Codex 凭证 |
| `logs/` | 运行日志 |

`accounts.jsonl` 里每行的主要字段：

```json
{
  "email": "xxx@outlook.com",
  "status": "success",
  "access_token": "eyJ...",
  "refresh_token": "",
  "account_id": "...",
  "password": "注册时设置的密码",
  "phone": "本单用掉的手机号",
  "liveness": "alive",
  "plan": "free",
  "quota": 19,
  "quota_note": "可生图 19 次",
  "activation": "success",
  "created_at": "2026-10-02T12:00:00+00:00"
}
```

## 四、设置里都有什么

界面上只需要管一两个字段，其余都在左下角**设置**里，默认值已经调好，看不懂的别动。

| 分组 | 关键项 | 说明 |
| --- | --- | --- |
| 网络 | 代理地址 | 留空自动用系统代理（Clash/FlClash 设的那个）；都没有才直连 |
| 浏览器 | 后台运行 / 拟人化 / 伪装地区 | 排查问题时把「后台运行」关掉就能看到窗口 |
| 注册 | 并发数、验证码等待 | 并发保持 1，等待别低于 180 秒 |
| 生图 | 超时 | 一般不用改 |
| 桌面端激活 | 开关 | 见下一节 |

## 五、「ChatGPT 桌面端激活」是什么

默认关闭，**和生图无关**。开启后，每个账号注册完成时会**复用同一个浏览器窗口**
跑一遍 Codex OAuth 授权：

```
清掉注册留下的登录态
  → 打开 Codex 授权页
  → 邮箱登录 + 邮箱验证码（复用本单的邮箱订单收码）
  → 手机号验证（号码由号池自动提供，失败会自动换号）
  → 授权确认 → 捕获回调 → 换 token
  → 凭证写入 data/codex_credentials/
```

号池侧对号码有号段成功率的统计：某个号段近期表现差，会自动在取号时避开它，
你不需要干预。

没有号池余额就别开这个开关，注册本身不一定需要手机号（只有 OpenAI 要求时才走）

### 刷新凭证

只有做过桌面端激活的账号才有 `refresh_token`。之后在账号池点 **刷新凭证**
（走 `/api/credentials/refresh`），就能批量换新的 `access_token`。

> 注册流程从 `/api/auth/session` 拿到的是 ChatGPT session token，**没有**
> refresh 能力，所以纯注册的账号不在刷新范围内。

## 六、常见问题

**Q：提示「没有找到 Python」**
装 Python 时没勾 *Add Python to PATH*。重新装一次，或者手动把 Python 目录加进系统 PATH。

**Q：依赖安装失败 / 卡住**
多是网络问题。用国内镜像重试：

```bat
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Q：提示「未创建工具密钥」/ 401**
工具密钥没填、填错、或者填的不是本站生成的那把。去「自建号池」页面重新生成一次，
粘进设置里保存。

**Q：提示余额不足**
工具密钥所属账号的余额不够下单了，去站点充值后再跑。

**Q：注册失败，提示风控 / 页面元素找不到**
- 换个干净一点的代理（出口 IP 很重要，机房 IP 最容易被人机验证挡住）
- 把「并发数」降到 1
- 在设置里把「后台运行浏览器」关掉，你能看到它卡在哪一步

**Q：一直卡在手机号验证 / 收不到短信**
号池会在超时后自动换号，等它换；连续几个都不行说明当时那条线路在风口上，
过 20~30 分钟再跑比硬砸更有效。

**Q：查额度失败 / 显示「未知」**
- 「未知」不等于 0：接口里如果没有 `image_gen` 这一项，就是未知，
  通常仍然能生图，直接去测试生图页试一张最快。
- 「token 已失效（HTTP 401）」才是真的死号。403 / 429 是风控或限流，
  过一会儿再试，别急着删号。

**Q：生图报「连接失败 / 超时」**
先看能不能连上 ChatGPT。设置里的代理留空时会自动读系统代理；
如果你用的是 TUN 模式或者手动填过代理，就在设置里显式填一次。

**Q：生图报「额度已用尽」**
等重置时间到（日志里会打出来），或者换一个号。免费号是 24 小时滚动窗口。

**Q：账号文件能直接给别的工具用吗**
能。`data/accounts_export.json` 是标准 JSON，`data/codex_credentials/*.json` 是
CLIProxyAPI 的 CodexTokenStorage 格式。

## 七、目录结构

```
gpt-register-lite/
├── run.bat                  双击入口
├── app.py                   本地 GUI 服务端
├── ui/index.html            界面（单文件，无前端依赖）
├── core/
│   ├── browser_flow.py      ChatGPT 注册页面流程
│   ├── oauth_flow.py        Codex 授权页面流程
│   ├── cloak_driver.py      CloakBrowser 的 Selenium 风格适配
│   ├── registration.py      单账号注册编排
│   ├── oauth.py             桌面端激活编排
│   ├── liveness.py          查活
│   ├── engine.py            并发任务引擎
│   ├── mailbox/             邮箱来源（本站号池）
│   ├── sms.py               号码来源（本站号池）
│   ├── quota.py             只读查生图额度
│   ├── imagegen.py          纯协议生图（sentinel + PoW + SSE）
│   ├── importer.py          粘贴导入解析（session JSON / token / 数组）
│   ├── netproxy.py          系统代理自动发现
│   ├── jobs.py              轻量后台任务（查额度 / 生图）
│   ├── settings.py          配置
│   ├── store.py             账号落库
│   ├── profile.py           随机姓名/生日
│   └── humanize.py          人工操作节奏
└── data/                    你的数据（不进版本库）
```

## 八、打包成 exe 给别人用

```bat
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\pyinstaller.exe --clean --noconfirm build.spec
```

产物是 `dist\AI小工具.exe`（约 70MB），**单文件，拷走就能双击运行**，
目标机器不需要装 Python。

打包后 `data\` 和 `logs\` 会生成在 exe 旁边（见 `core/paths.py`），
所以换新 exe 不会丢账号。

> 浏览器内核（约 150MB）不在包里，第一次跑会自动下载到 `%USERPROFILE%\.cloakbrowser`。
> 离线环境下可以提前把这个目录拷到目标机器。
